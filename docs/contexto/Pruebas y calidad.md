- [[avisos-y-catalogo.spec.js]]: la tienda pinta las tarjetas aunque `/api/catalogo` tarde 4 s, el catálogo remoto actualiza las tarjetas y sigue en la siguiente visita aunque la red falle (`dstar_catalog`), el formulario del próximo drop no envía sin consentimiento, la ficha ofrece aviso solo para las tallas agotadas y el panel muestra el embudo y el botón AVISAR. Como Playwright pone `navigator.webdriver`, [[metricas.js]] no manda eventos durante las pruebas.
